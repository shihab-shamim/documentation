Introduction

Chart Block turns rows of numbers into interactive charts right inside the block editor, with no code and no separate charting tool.

You enter your labels and values as datasets, pick a chart type, and the block draws the chart as you edit. From there you can set the width and height, background and text colors, scales and grid lines, add a title and subtitle, and let visitors download the chart.

Typical uses include sales reports, survey results, and site statistics. With Chart Block Pro you can also keep a chart in sync with live data from Google Sheets or WooCommerce.

Requirements

Chart Block runs on a standard WordPress site. Before you begin, check that yours meets these minimums:

  • Download: Chart Block
  • WordPress Version: 6.5 or higher
  • PHP Version: 7.1 or higher

Installation

Chart Block is listed in the WordPress plugin directory, so you can install it from the dashboard, upload the zip file yourself, or add it straight from the block editor.

1st Way: Install by Search

The quickest route: install Chart Block without leaving your dashboard.

  1. In your WordPress dashboard, go to Plugins > Add New.
  2. Type “Chart Block” into the search box, then click Install Now.

When the install finishes, click Activate to switch Chart Block on.

2nd Way: Install by Upload

Use this method when you already have the chart-block.zip file on your computer.

  1. Download the latest version of Chart Block (.zip file).
  2. Log in to your WordPress admin dashboard.
  3. Click Plugins in the left-hand menu.
  4. At the top of the page, click Add New.
  5. Click Upload Plugin.
  6. Click Choose File, then select chart-block.zip.
  7. Click Install Now.
  8. Activate the plugin.

3rd Way: Install from Gutenberg Editor

Handy when you are already editing a page and want to drop a chart in right away.

  1. Open the Gutenberg editor and click the plus icon in the top left corner.
  2. Search for Chart Block. It appears under Available to Install.
  3. Click it to install the plugin and add the block to your page.

Complete Onboarding Setup

Right after activation, Chart Block opens a short welcome screen.

Click Allow & Continue to subscribe to the newsletter and get plugin updates and news.

You then arrive at the Chart Block dashboard.

License Activation

If you bought Chart Block Pro, activate your license key to unlock the Pro features, such as Live Data Hub and the extra chart types.

Go to Plugins » Chart Block » Active License.

  1. Click Activate License. A popup opens.
  2. Enter your license key in the field.
  3. Agree to send your website URL, email, and license key to the plugin server for verification.
  4. Click Activate License.
Next step

Your plugin is ready. Head to How To Use to add your first chart.

How To Use

How To Use Chart Block

You can easily create charts with the Chart Block.

Enter your data, choose a chart type, and add labels as needed. The styling controls let you adjust the colors and typography to match the chart to your site.

Add to the Page

You can find Chart Block in the block library and add it anywhere on your page.

The block arrives with a default design that you can edit right away.

Editor View

Select the block, and its settings open in the sidebar on the right.

Choose a Chart Type

The Chart Type dropdown lists 10 chart types: Combo, Bar, Pie, Line, Scatter, Radar, Gauge, Funnel, Heatmap, and Candlestick. The free version includes the Combo chart, and the other nine come with Chart Block Pro (see More Chart Types). Pick the type that presents your data best.

Add or Remove Datasets

You can manage the chart's datasets from the Add or Remove Datasets panel. Edit a dataset to update its data, click Add New Dataset to add another one, or click the ✕ icon to remove it.

Chart Settings

You can customize the chart's appearance from the Chart Settings panel. Select the chart Type, then set its Width and Height. Pie, Doughnut, and Polar Area charts use a single dataset. You can also choose the Background and Text Color, show or hide the X and Y scales and grid lines, and set the Grid Line Color.

Title & Subtitle Settings

You can add a title and subtitle from the Title & Subtitle Settings panel. Turn on Show Title to display a title, then enter your text and set its Font Size and Color. Turn on Show Subtitle to display a subtitle below the title.

Download Settings

You can let visitors download your chart from the Download Settings panel. Turn on Download Button to display a Download Chart button above the chart.

Pro Features

The features in this section are available with Chart Block Pro. Pro

Live Data Hub

You can connect a spreadsheet to your chart and keep its data up to date with Live Data Hub. Turn it on, then choose how often the chart syncs from the Sync every dropdown. The editor shows the latest synced values.

Click Refresh now to sync the data immediately, or Setup page to connect your spreadsheet.

Connect a Data Source

You can connect your chart to live data from the setup page, under Chart > Help And Demo > Resources. Turn on Live Data Hub, then select a data source: Google Sheets or WooCommerce. Click Setup Guidelines and follow the steps to complete the connection. The status changes from Disconnected once your data source is connected.

More Chart Types

Chart Block Pro adds 9 more chart types: Bar, Pie, Line, Scatter, Radar, Gauge, Funnel, Heatmap, and Candlestick. Select one from the Chart Type dropdown, then adjust the settings to match your data and design.

Shortcode Usage

You can display a chart anywhere on your site with a shortcode.

Build it once, then paste its shortcode into any page, post, or widget instead of rebuilding it each time.

Add New ShortCode

Go to the dashboard menu and click Add New Chart.

The block editor opens, where you can build and style the chart. When you are happy with it, click Save and copy the shortcode shown on the page.

Now go back to the dashboard menu.

Insert Shortcode & Preview

Paste the shortcode into any page, post, or widget area where you want it to appear. Use the live preview to check how it looks before you publish.

Publish or save the page, then visit your site to see the result.

FAQ’s

FAQ – Chart Block

1. What is Chart Block?

Chart Block is a Gutenberg block that turns your data into charts. You can use it for sales reports, survey results, statistics, and other data you want visitors to understand at a glance.

2. Which chart types are available?

The free version includes the Combo chart. Chart Block Pro adds 9 more: Bar, Pie, Line, Scatter, Radar, Gauge, Funnel, Heatmap, and Candlestick.

3. Can I customize the chart's appearance?

Yes. You can change the width, height, background, text color, X and Y scales, grid lines, and grid line color, and add a title and subtitle with their own font size and color.

4. Can visitors download the chart?

Yes. Turn on Download Button to let visitors download the chart.

5. Can I use live data?

Yes. With Live Data Hub in Chart Block Pro, you can connect your chart to a spreadsheet and choose how often the data syncs.

6. Is Chart Block responsive?

Yes. You can set the chart width as a percentage, so it adapts to different screen sizes.

7. Do I need coding knowledge?

No. You can create and customize charts directly in the block editor without writing code.

8. How do I use Chart Block?

Install and activate the plugin, then add Chart Block from the block library. Choose a chart type, enter your data, adjust the settings in the sidebar, and publish the page.
