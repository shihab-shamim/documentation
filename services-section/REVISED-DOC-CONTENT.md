### Introduction

Services Section Block lets you build a professional services section for your WordPress site
without writing any code.

You can present what you offer as a row of cards, each with its own icon or image, title,
description, and link. Pick a layout, set the columns and spacing, then adjust the colors and
typography until the section matches the rest of your site. It works just as well for a business
site, an agency page, or a personal portfolio.

### Requirements

You will need the following:

- **Download:** Services Section Block
- **WordPress Version:** 6.5 or higher
- **PHP Version:** 7.1 or higher

### Installation

You can install the plugin in three ways. Pick whichever is easiest for you.

#### 1st Way: Install by Search

You can install the plugin straight from the WordPress plugin directory.

1. Go to your WordPress dashboard and navigate to Plugins > Add New.
2. Search for Services Section Block, then click Install Now.

[Screenshot 1]

Once the installation finishes, click Activate.

#### 2nd Way: Install by Upload

[Screenshot 2]

1. Download the latest version of Services Section Block (.zip file).
2. Log in to your WordPress admin dashboard.
3. Click Plugins in the left-hand menu.
4. At the top of the page, click Add New.
5. Click Upload Plugin.
6. Click Choose File, then select services-section-block.zip.
7. Click Install Now.
8. Activate the plugin.

#### 3rd Way: Install from Gutenberg Editor

[Screenshot 3]

1. Open the Gutenberg editor and click the plus icon in the top left corner.
2. Search for Services Section Block. It appears under Available to Install.
3. Click it to add the block to your editor.

[Screenshot 4]

Navigate to Plugins » Services Section Block » Active License.

2. Enter your license key in the field.
3. Agree to send your website URL, email, and license key to the plugin server for verification.

## How To Use

### How To Use Services Section

You can easily showcase your services with the Services Section block.

Add as many service items as you need, then set the title, description, and icon or image for each
one. The layout and styling controls let you match the section to the rest of your site.

#### Add to the Page

You can find Services Section Block in the block library and add it to any section of your page.
Services Section Pro gives you 8+ extra service blocks if you want a different layout.

[Screenshot 9]

The block arrives with a default design that you can edit right away.

#### Editor View

Select the block, and its settings open in the sidebar on the right.

[Screenshot 10] — caption: Services Section Block- Sidebar Settings.

#### Choose a Layout

You can choose from nine layouts: Default and Layout-1 through Layout-8. Pick the one that suits
your site best. Keep in mind that some settings change when you switch to a different layout.

[Screenshot 11]

#### Choose Columns, Background & Spacing

You can set how many cards appear in a row, with separate values for desktop, tablet, and mobile.
Column Gap and Row Gap control the space between the cards, while Background and Padding apply to
the section as a whole.

[Screenshot 12]

#### Item Card Border, Radius & Shadow

You can round the card corners, add a border, and apply a shadow. Hover effects are available too,
so the cards react when someone points at them.

[Screenshot 13]

#### Title & Description Typography

You can set the font size, text color, and hover color for the card title and description. Each one
has its own settings for different screen sizes.

[Screenshot 14]

#### Links & Buttons

You can make the whole card, just its title, or the button clickable, and choose whether the link
opens in the same tab or a new one.

[Screenshot 15]

### Shortcode Usage

You can display a services section anywhere on your site with a shortcode.

Build the section once, then paste its shortcode into any page, post, or widget instead of
rebuilding it each time.

#### Add New ShortCode

Go to the dashboard menu and click Add New Service.

[Screenshot 16]

The block editor opens, where you can build and style the section. When you are happy with it,
click Save and copy the shortcode shown on the page.

[Screenshot 17]

Now go back to the dashboard menu.

[Screenshot 18]

#### Insert Shortcode & Preview

Paste the shortcode into any page, post, or widget area where you want the section to appear. Use
the live preview to check how it looks before you publish.

[Screenshot 19]

Publish or save the page, then visit your site to see the result.

[Screenshot 20]

## FAQ's

### FAQ – Services Section

**1. What is the Services Section?**

It is a custom Gutenberg block that displays your services as a set of cards. You can use it for
services, features, offerings, or any other content you want to present that way.

**2. Is the Services Section compatible with all WordPress themes?**

It works with any theme that supports the Gutenberg block editor.

**3. Is the Services Section responsive?**

Yes. The section adapts to desktops, tablets, and mobile screens.

**4. Can I customize the service cards?**

Yes. You can change the layout, spacing, typography, colors, borders, shadows, and hover effects to
match your site.

**5. Can I choose different layouts?**

Yes. Nine layouts are available: Default and Layout-1 through Layout-8.

**6. Can I add icons or images to my services?**

Yes. Each card can show an icon or an image alongside its title and description.

**7. Can I make a service card or button clickable?**

Yes. You can link the whole card, its title, or the button, and control how the link opens.

**8. Can I customize the typography for each service?**

Yes. Font size, text color, and hover color can be set for titles and descriptions, with separate
values for each screen size.

**9. Can I control the spacing and number of cards per row?**

Yes. You can set how many cards appear in each row, the gap between them, and the padding around
the section.

**10. How do I use the Services Section?**

Install and activate the plugin, then add the block from the Gutenberg editor. Choose a layout,
fill in your service content, adjust the settings in the sidebar, and publish the page.
