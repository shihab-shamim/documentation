Services Section Block

Welcome to the Services Section Block documentation. Here you will learn how to showcase what your business offers in a clean row of service cards.

Start with Getting Started to install the plugin and activate your license. How To Use then covers layouts, columns, card styling, typography, and links, and shows how to reuse a section with a shortcode. The FAQs answer common questions.

Introduction

You can easily showcase your services with the Services Section Block.

Add as many service items as you need, then set the title, description, and icon or image for each one. The layout and styling controls let you match the section to the rest of your site.

Requirements

To use Services Section Block, your site needs:

  • Download: Services Section Block
  • WordPress Version: 6.5 or higher
  • PHP Version: 7.1 or higher

Installation

Choose any one of the three installation methods below.

1st Way: Install by Search

Find and install the plugin without leaving your dashboard.

  1. In your WordPress dashboard, go to Plugins > Add New.
  2. Type “Services Section Block” into the search box, then click Install Now.

When it is installed, click Activate to switch Services Section Block on.

2nd Way: Install by Upload

Upload the zip file manually if you already have it on your computer.

  1. Download the latest version of Services Section Block (.zip file).
  2. Log in to your WordPress admin dashboard.
  3. Click Plugins in the left-hand menu.
  4. At the top of the page, click Add New.
  5. Click Upload Plugin.
  6. Click Choose File, then select services-section-block.zip.
  7. Click Install Now.
  8. Activate the plugin.

3rd Way: Install from Gutenberg Editor

Install the block straight from the editor while you are building a page.

  1. Open the Gutenberg editor and click the plus icon in the top left corner.
  2. Search for Services Section Block. It appears under Available to Install.
  3. Click it to install the plugin and add the block to your page.

Complete Onboarding Setup

On first activation, Services Section Block shows a brief guided setup.

Click Allow & Continue to subscribe to our newsletter and stay up to date with plugin updates and news.

You are then taken to the plugin dashboard.

License Activation

Have Services Section Pro? Activate your license to unlock the extra service blocks.

Go to Plugins » Services Section Block » Active License.

  1. Click Activate License. A popup opens.
  2. Enter your license key in the field.
  3. Agree to send your website URL, email, and license key to the plugin server for verification.
  4. Click Activate License.
Next step

How To Use

How To Use Services Section

You can easily showcase your services with the Services Section block.

Add as many service items as you need, then set the title, description, and icon or image for each one. The layout and styling controls let you match the section to the rest of your site.

Add to the Page

You can find Services Section Block in the block library and add it to any section of your page. Services Section Pro gives you 8+ extra service blocks if you want a different layout.

The block arrives with a default design that you can edit right away.

Editor View

Select the block, and its settings open in the sidebar on the right.

Choose a Layout

You can choose from nine layouts: Default and Layout-1 through Layout-8. Pick the one that suits your site best. Keep in mind that some settings change when you switch to a different layout.

Choose Columns, Background & Spacing

You can set how many cards appear in a row, with separate values for desktop, tablet, and mobile. Column Gap and Row Gap control the space between the cards, while Background and Padding apply to the section as a whole.

Item Card Border, Radius & Shadow

You can round the card corners, add a border, and apply a shadow. Hover effects are available too, so the cards react when someone points at them.

Title & Description Typography

You can set the font size, text color, and hover color for the card title and description. Each one has its own settings for different screen sizes.

Links & Buttons

You can make the whole card, just its title, or the button clickable, and choose whether the link opens in the same tab or a new one.

Shortcode Usage

You can display a services section anywhere on your site with a shortcode.

Build the section once, then paste its shortcode into any page, post, or widget instead of rebuilding it each time.

Add New ShortCode

Go to the dashboard menu and click Add New Service.

The block editor opens, where you can build and style the section. When you are happy with it, click Save and copy the shortcode shown on the page.

Now go back to the dashboard menu.

Insert Shortcode & Preview

Paste the shortcode into any page, post, or widget area where you want the section to appear. Use the live preview to check how it looks before you publish.

Publish or save the page, then visit your site to see the result.

FAQ’s

FAQ – Services Section

1. What is the Services Section?

It is a custom Gutenberg block that displays your services as a set of cards. You can use it for services, features, offerings, or any other content you want to present that way.

2. Is the Services Section compatible with all WordPress themes?

It works with any theme that supports the Gutenberg block editor.

3. Is the Services Section responsive?

Yes. The section adapts to desktops, tablets, and mobile screens.

4. Can I customize the service cards?

Yes. You can change the layout, spacing, typography, colors, borders, shadows, and hover effects to match your site.

5. Can I choose different layouts?

Yes. Nine layouts are available: Default and Layout-1 through Layout-8.

6. Can I add icons or images to my services?

Yes. Each card can show an icon or an image alongside its title and description.

7. Can I make a service card or button clickable?

Yes. You can link the whole card, its title, or the button, and control how the link opens.

8. Can I customize the typography for each service?

Yes. Font size, text color, and hover color can be set for titles and descriptions, with separate values for each screen size.

9. Can I control the spacing and number of cards per row?

Yes. You can set how many cards appear in each row, the gap between them, and the padding around the section.

10. How do I use the Services Section?

Install and activate the plugin, then add the block from the Gutenberg editor. Choose a layout, fill in your service content, adjust the settings in the sidebar, and publish the page.
