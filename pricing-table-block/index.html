Pricing Table Block

This is the official Pricing Table Block documentation. Use it to build clear, easy-to-compare pricing tables for your plans, packages, and memberships.

Begin with Getting Started to install the plugin and activate your license. How To Use then covers plans, features, buttons, layout, and styling, plus how to reuse a table with a shortcode. The FAQs cover the most common questions.

Introduction

Pricing Table Block helps visitors compare your offers at a glance by showing each plan side by side with its price, feature list, and call-to-action button.

For every plan you set a name, price, currency, and billing period, list what is included, and add a button that links to your sign-up or checkout page. Then pick a style, choose how many columns show on each device, and adjust the padding and shadow.

It suits subscription plans, service packages, product tiers, and memberships. Pricing Table Pro adds more themes and 11+ ready-made pricing blocks for industries such as SaaS, web hosting, and online courses.

Requirements

Pricing Table Block needs the following:

  • Download: Pricing Table Block
  • WordPress Version: 6.5 or higher
  • PHP Version: 7.1 or higher

Installation

You can add Pricing Table Block to your site in any of these three ways.

1st Way: Install by Search

The simplest option: find and install the plugin from your dashboard.

  1. In your WordPress dashboard, go to Plugins > Add New.
  2. Type “Pricing Table Block” into the search box, then click Install Now.

Once it is installed, click Activate to turn the plugin on.

2nd Way: Install by Upload

Use this if you have the b-pricing-table.zip file on your computer.

  1. Download the latest version of Pricing Table Block (.zip file).
  2. Log in to your WordPress admin dashboard.
  3. Click Plugins in the left-hand menu.
  4. At the top of the page, click Add New.
  5. Click Upload Plugin.
  6. Click Choose File, then select b-pricing-table.zip.
  7. Click Install Now.
  8. Activate the plugin.

3rd Way: Install from Gutenberg Editor

Install it on the spot while you are editing a page.

  1. Open the Gutenberg editor and click the plus icon in the top left corner.
  2. Search for Pricing Table Block. It appears under Available to Install.
  3. Click it to install the plugin and add the block to your page.

Complete Onboarding Setup

When you activate Pricing Table Block for the first time, a short setup screen greets you.

Click Allow & Continue to subscribe to our newsletter for plugin updates and news.

You are then taken to the plugin dashboard.

License Activation

If you have Pricing Table Pro, activate your license to unlock its extra themes and pricing blocks.

Go to Plugins » Pricing Table Block » Active License.

  1. Click Activate License. A popup opens.
  2. Enter your license key in the field.
  3. Agree to send your website URL, email, and license key to the plugin server for verification.
  4. Click Activate License.
Next step

Next, open How To Use to create your first pricing table.

How To Use

How To Use Pricing Table

You can easily create a pricing table with the Pricing Table block.

Add as many plans as you need, then set the title, price, features, and button for each one. The layout and styling controls let you match the table to the rest of your site.

Add to the Page

You can find Pricing Table in the block library and add it anywhere on your page.

The block arrives with a default design that you can edit right away.

Editor View

Select the block, and its settings open in the sidebar on the right.

Choose a Style

You can choose from three styles: Basic, Standard, and Ultimate. Click the Styles icon at the top of the block sidebar, then select the style that suits your site best.

Add or Remove Prices

You can manage your plans from the Add or Remove Prices panel. Click Add New Price to create a plan, then set its Plan Name, Price, Currency, and Period.

Use Add New Feature to add a feature, or click the ✕ icon to remove one. Set the Button Label and Link, then choose a Color for the plan. Click Duplicate to copy a plan with its settings, or Remove to delete it.

Layout Settings

You can control how your plans are arranged from the Layout Settings panel. Set the number of Columns for desktop, tablet, and mobile using the device icons. Column Gap and Row Gap control the space between the plans.

Plan Card Style

You can style the plan cards from the Pricing Table panel in the Style tab. Set the Padding for the top and bottom or left and right, or switch to setting each side separately. Add a Shadow to make the cards stand out.

Pro Features

The features in this section are available with Pricing Table Pro. Pro

Choose Style

You can choose from six themes: Default, Horizontal, Minimal, Dark, Switchable, and Dark Minimalist. Select a theme from the block toolbar or from the Choose Style dropdown to change the look of your pricing table.

Additional Blocks

Pricing Table Pro also gives you 11+ ready-made pricing blocks for different industries, including SaaS Pricing, Web Hosting Pricing, Online Course Pricing, and Restaurant & Catering Pricing. You can find them in the block library and add them anywhere on your page.

Shortcode Usage

You can display a pricing table anywhere on your site with a shortcode.

Build it once, then paste its shortcode into any page, post, or widget instead of rebuilding it each time.

Add New ShortCode

Go to the dashboard menu and click Shortcodes.

The block editor opens, where you can build and style the pricing table. When you are happy with it, click Save and copy the shortcode shown on the page.

Now go back to the dashboard menu.

Insert Shortcode & Preview

Paste the shortcode into any page, post, or widget area where you want it to appear. Use the live preview to check how it looks before you publish.

Publish or save the page, then visit your site to see the result.

FAQ’s

FAQ – Pricing Table

1. What is the Pricing Table Block?

It is a Gutenberg block that lets you create customizable pricing tables. You can use it for subscription plans, service packages, product tiers, and membership options.

2. Can I add multiple plans?

Yes. You can add as many plans as you need and display them side by side.

3. Can I add a feature list to each plan?

Yes. Each plan can have its own feature list, which makes it easy for visitors to compare your offerings.

4. Can I add a button to each plan?

Yes. Each plan can have a button with a custom link, such as a sign-up or checkout page.

5. Can I customize the table design?

Yes. You can change the layout, columns, spacing, colors, and typography to match your site.

6. Are different themes available?

Yes. Pricing Table includes built-in styles, and Pricing Table Pro adds more themes.

7. Is Pricing Table responsive?

Yes. The pricing tables adapt to desktops, tablets, and mobile screens.

8. How do I use Pricing Table?

Install and activate the plugin, then add Pricing Table from the block library. Add your plans, adjust the settings in the sidebar, and publish the page.
