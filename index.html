Introduction

Info Cards is a block plugin for the WordPress block editor. It adds an Info Cards category to the block inserter and gives you blocks that lay text, images and links out as a row or grid of cards.

You build a card layout the same way you build any other block content. Add the block to a post or page, type the title and description straight onto the card in the canvas, pick an image, and set the columns, gaps, colours and typography from the block sidebar. Nothing has to be written in code.

The plugin is a good fit if you present repeated pieces of content in a uniform shape: service summaries, team members, product highlights, feature lists or link collections. The same card layout can also be saved once and reused anywhere on the site through a shortcode, so it works outside the block editor too.

The free build registers one block, Info Cards, with six themes. The Pro build unlocks seven more themes inside that block and adds eight further card blocks. Everything in this documentation that is Pro only is marked with a Pro badge.

Note The package that ships the premium features is named Info Cards Pro in the plugins list. It is the same plugin as the free Info Cards, and it deactivates the free copy on activation so the two never run at once.

Requirements

  • Download: info-cards.3.0.2.zip
  • WordPress Version: 6.5 or later
  • PHP Version: 7.4 or later

Installation

1st Way: Install by Search

  1. Go to Plugins → Add New in your WordPress admin dashboard.
  2. Type Info Cards into the search field.
  3. Click Install Now on the Info Cards plugin by bPlugins.
  4. Click Activate.

2nd Way: Install by Upload

  1. Download info-cards.3.0.2.zip from the WordPress.org plugin page.
  2. Go to Plugins → Add New → Upload Plugin.
  3. Choose the zip file and click Install Now.
  4. Click Activate.

If you prefer to upload by FTP, unzip the file and copy the info-cards folder into /wp-content/plugins/, then activate the plugin from the Plugins screen.

3rd Way: Install from Gutenberg Editor

  1. Open the post or page where you want the cards.
  2. Click the + button in the block editor and search for Info Cards.
  3. The editor suggests matching blocks from the block directory. Click the Info Cards block by bPlugins to install and insert it in one step.
  4. The block is added to your content and the plugin is now active on the site.

Complete Onboarding Setup

After activation the plugin opens its welcome screen at Info Cards → Help And Demo. You can also reach it from the Help And Demo link next to Info Cards on the Plugins screen.

The Welcome page has a Getting Started panel with four tabs, one for each way of placing a card layout. Pick the tab that matches how you build pages:

Tab What it walks you through
Gutenberg Add the block, pick a layout, add your content, then style and publish. The Open Editor button starts a new post for you.
Shortcode Create a card layout under Info Cards → Add New, publish it, copy its shortcode, then paste the shortcode wherever you need it.
Elementor Build and publish a card layout, then drop Elementor's Shortcode widget into your design and paste the shortcode into it.
PHP Take the ID from the ShortCodes list and call it from a template file with do_shortcode.

The same screen carries a Start Now button. It creates a new page already titled Info Cards with the Info Cards block inserted, so you can go straight to editing.

The Info Cards Admin Menu

Activating the plugin adds an Info Cards item to the WordPress admin menu. It is available to users who can manage options. Under it you get:

  • Help And Demo: the plugin dashboard, described below.
  • Analytics: the card click report. See How To Use.
  • ShortCodes: the saved card layouts you can embed anywhere with a shortcode.

The Help And Demo dashboard has its own left-hand navigation:

Settings: data on uninstall

By default your settings and data stay in the database even if you deactivate or uninstall the plugin. The Settings page lets you change that with the Delete plugin data on uninstall switch. When it is on, uninstalling the plugin permanently removes its posts and custom post types, settings and options, layout configuration and meta data, taxonomy terms, and all tracking and analytics data.

Warning Turning the switch on asks you to type a confirmation first, because there is no way to recover the data once the plugin is uninstalled. Take a backup before you enable it.

License Activation

This section applies to the Pro build only. The licence screen is not present in the free plugin.

  1. Go to Info Cards → Help And Demo and open License Activation.
  2. Paste the License key you received with your purchase into the field.
  3. Click Activate License and wait while the plugin contacts the licence server.
  4. When the key is accepted the page shows Your license is active and the Pro blocks and themes become available in the editor.

The same screen lets you show, hide or copy the stored key, change it for a different one, or click Deactivate license to release the key so you can move it to another site. Deactivating stops premium features and automatic updates on this site until you activate again. If you cannot find your key, use the Recover license link on that screen.

Note Licensing runs through Freemius. The activation screen lists exactly what is sent for updates and security patches: your homepage URL, plugin version, SDK version, and whether the plugin is active, deactivated or uninstalled.

How To Use Info Cards

Info Cards is the free block and the one most layouts start from. It renders a grid of cards, each with a background, an optional image, a title, a description and an optional button. A theme decides the overall look, and the theme you choose changes which style controls the sidebar offers.

Add to the Page

  1. Open the post or page you want to edit.
  2. Click the + button, or type /Info Cards in an empty paragraph.
  3. Select Info Cards from the Info Cards category.
  4. The block drops in with three sample cards you can edit straight away.

Editor View

Most of the card content is edited on the canvas rather than in the sidebar. Click a card title and type over it, click the description and type over that, and click the button label to rename it. Empty fields show the placeholders Enter Title, Enter Description and Button.

To set a picture, use the Card Image control on the card. You can upload a file, pick one from the media library, or paste an image URL.

The block toolbar above the block holds the alignment buttons, which place the whole block to the left, centre or right, and a theme picker with a thumbnail of each theme.

Themes

Open the General tab in the block sidebar. The first panel is Themes, with a single Choose A Theme dropdown.

Theme Availability
Default, Theme 1, Theme 2, Theme 3, Theme 4, Theme 5 Free
Theme 6, Theme 7, Theme 8, Theme 9, Theme 10, Theme 11, Theme 12 Pro

Switching theme rewrites several settings at once. Choosing Default, Theme 1 or Theme 2, for example, sets three desktop columns and a vertical layout, while Theme 3 switches to two columns and a horizontal layout. The editor shows a note reminding you that changing theme returns certain settings to their default values, so pick your theme before you spend time on the styling.

Note Theme 10 uses a mouse movement animation that runs on the front end only. The editor shows a static preview of it.

Add or Remove Cards

The Add or Remove Cards panel lists every card in the block. Open a card by its title to reach its own settings:

  • Background: the card's background colour.
  • Card Url: a link for the whole card.
  • Image Url: the card image address, shown when Show Image is on.
  • Button Url: where the card's button points.
  • Button Show: show or hide the button on this card.

At the bottom of each card sit Delete and Duplicate, and at the bottom of the panel Add New Card. Delete only appears once there is more than one card.

How To Use Player Cards Pro

Player Cards presents people or profiles. Each card carries an avatar, a name, a role, a city, a joining date, a level, a points figure, a group name, a short description and a list of stats.

Add to the Page

Click + in the editor, open the Info Cards category and choose Player Cards. The block starts with two demo profiles.

General Tab

  • Add Or Remove Cards: each card holds an Avatar Image, Name, Role, Group Name, City, Joined Date, Level, Points, Description, a Theme Class, and a stats list where each entry has a Title, an Icon and a Value.
  • Layouts: columns per device, set to two on desktop and one on tablet and mobile, plus the row and column gaps.
  • Elements: a switch for each part of the card. Show Name, Show Role, Show City, Show Joined, Show Group Name, Show Level, Show Points, Show Stats, Show Description and Show Prompt, with a Card Prompt field for the prompt text.

Style Tab

Panels: Container, Card, Image, Name, Description, Role, City, Joined, Group Name, Level, Points, Stats, Prompt and Sidebar. Several of them offer a green and a red colour, so a card can carry one of two accent treatments.

How To Use News Cards Pro

News Cards lays articles out as cards with a date block, an author, a title, an excerpt, extra stats and a button. It can run on cards you type by hand or on your real posts.

General Tab

  • Add Or Remove Cards: each card has a day, month and year, an author, a title, an excerpt, additional info, an image and a button.
  • Layouts: columns per device, three on desktop, two on tablet and one on mobile, plus the gaps.
  • Elements: Show Date, Show Author, Show Title, Show Description, Show Button, Show Stats Info, Open In New Tab and Light Style.
  • Posts Query: the controls that turn the block into a live post list.

Posts Query

Switch the block to your posts and the Posts Query panel decides which ones appear:

  • Taxonomy Relation: AND or OR between the taxonomy filters.
  • Select Categories, Select Tags and Select Authors.
  • Search Query: limit the list to posts matching a search term.
  • Post Offset: skip the first few results. Defaults to 0.
  • Include Posts and Exclude Posts: pick specific posts in or out.
  • Exclude Current Post and Exclude Sticky Posts.

The block queries the post type by default, shows 6 posts, orders them by date descending, uses the full image size and formats dates as M j, Y.

Style Tab

Panels: Container, Card, Date, Stats, Author Name, Title, Description and Button. Because this block has a dark and a light presentation, several colour controls are labelled Dark Style and Light Style so you can set both.

Shortcode Usage

A shortcode lets you reuse one card layout in places the block editor does not reach, such as a widget area, a page builder or a theme template.

Create a shortcode layout

  1. Go to Info Cards → Add New.
  2. Give it a title so you can recognise it later, then build the cards exactly as you would in a post.
  3. Click Publish.
  4. Go to Info Cards → ShortCodes. The ShortCode column shows the shortcode for each saved layout. Click it to copy it to the clipboard.

Paste it where you need it

[icb id="123"]
Attribute Type Default Description
id Number 0 The ID of the saved layout under Info Cards → ShortCodes. Without a valid ID the shortcode outputs nothing.

Paste the shortcode into a post, a page, a text or shortcode widget, or a page builder element. In Elementor, drag in the Shortcode widget and paste it into the widget's input field.

Call it from a template

To output a layout from a theme or template file such as single.php or page.php, use do_shortcode and replace the ID with the one from the ShortCodes list. 

<?php echo do_shortcode('[icb id="123"]'); ?>
Note A shortcode layout follows the status of its post. A published layout is visible to everyone. Private, draft, pending and scheduled layouts only render for users who are allowed to see them, and a password protected layout shows the password form first.

Card Click Analytics

The plugin records clicks on links and buttons inside its blocks on the front end and reports them under Info Cards → Analytics. Clicks are grouped by card title, so give your cards real titles and real links if you want the report to be useful.

At the top of the page four figures cover the range you picked: Clicks, Cards clicked, Busiest day and Daily average, followed by a Clicks per day chart. You can view the last 7, 30 or 90 days.

Below that, Most clicked cards lists each card with a sparkline, its clicks In range, a Trend badge against the previous period, its All time total and when it was Last clicked. Sort by clicking a column heading, and narrow the list with Search cards.

Three controls sit at the bottom of the page:

  • Export CSV: download the current range as a spreadsheet file.
  • Keep history for: how long click history is retained. Choose 7 days, 30 days, 60 days, or As long as possible (90 days), which is the default. A daily job trims anything older.
  • Clear analytics: delete all recorded clicks. This cannot be undone.
Tip If the page says no clicks have been recorded yet, add an Info Cards block to a published page and give its cards real links. Clicks from logged out visitors are counted too, and obvious bot traffic is ignored.
